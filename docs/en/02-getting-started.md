# Getting started

## Assembly order

1. SMD passives **R1, R2, R3, C1, C2**  
2. **U1 TP4054** and **CHARGE** LED  
3. **USB-C** connector  
4. **Switch** and **Light** button  
5. Main **5 mm** LED (**+ / −** polarity)  
6. **CR2032** holder on the back · insert the cell  
7. Turn **Switch** on → press **Light**  

![Assembled light](../assets/images/en/ready.png)

![Two operating modes](../assets/images/en/two-modes.png)

- **SW ON** — constant light  
- **KEY** pressed — lights while held  

## In the box

- **14 parts**  
- **5 LEDs of different types**  
- **CR2032** cell included  
- Charge port: **USB-C**

## Power sources

The light can run from:

1. **USB-C** — power from the cable  
2. **CR2032** — coin cell in the holder  
3. **Li-ion / LiPo** — pack on **B(+) / B(−)**
