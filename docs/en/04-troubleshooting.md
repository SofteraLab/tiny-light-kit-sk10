# Troubleshooting

| Symptom | Check |
| --- | --- |
| LED dark | **Switch** on; **CR2032** inserted; LED polarity; **R1** |
| No CHARGE | **USB-C** cable; **U1 TP4054** joints; **CHARGE** LED |
| Board gets hot | Remove USB / battery; bridges on **U1** / **USB-C** |
| Button does nothing | **Light** button solder; cold joints |
| Dim light | Weak **CR2032**; try another of the **5** spare LEDs |
