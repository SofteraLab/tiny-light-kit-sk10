# Пошук несправностей

| Симптом | Що перевірити |
| --- | --- |
| LED не світить | **Switch** увімк; **CR2032** вставлена; полярність LED; **R1** |
| Немає CHARGE | Кабель **USB-C**; пайка **U1 TP4054**; індикатор **CHARGE** |
| Плата гріється | Зніміть USB / батарею; містки на **U1** / **USB-C** |
| Кнопка не діє | Пайка кнопки **Light**; холодні стики |
| Слабке світло | Сів **CR2032**; інший LED з комплекту **5 різних** |
